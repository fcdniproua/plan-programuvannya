Інструменти

  • Laravel Herd — на macOS ставить свіжий PHP 8.3+ одразу (вбудований у систему PHP не годиться)
  • VS Code + розширення PHP Intelephense
  • Git і акаунт на GitHub
  • Composer — знадобиться з 20-го уроку

Основні джерела

  • Laracasts: PHP for Beginners — безкоштовний курс від автора, чиї уроки вчать Laravel
  • Довідник php.net — відкривати щоразу, коли зустрілась незнайома функція
  • PHP: The Right Way — як писати сучасно, а не як у старих туторіалах

Розписані заняття

  • Уроки 1–4: перший місяць коду — запуск, змінні, введення даних, умови
  • Уроки 5–9: цикли і масиви — найважчий модуль блоку
  • Далі уроки розписуються так само, блоками

Тренажери

  • Exercism PHP — задачі з живим ревʼю
  • Codewars — по одній задачі 8 kyu на день
  • 3v4l.org — швидко перевірити шматок коду в браузері

Поки йде цей блок

Розрахунок: 24 уроки × 4–5 годин ≈ 110 годин практики. При 5 годинах на тиждень блок закривається приблизно за 5,5 місяця. Швидше — добре, повільніше — теж нормально, головне не пропускати уроки 16–20.
