Підготовка: один вечір з дорослим

Робиться разом і один раз, на macOS. Мета — щоб на першому занятті команда php -v уже працювала: боротьба зі встановленням убиває мотивацію швидше за будь-яку складну тему.

Що поставити

  1. Поставити Laravel Herd — безкоштовний, ставить свіжий PHP і сам прописує його в систему
  2. Відкрити Термінал (⌘ + Пробіл → «Термінал») і перевірити: php -v. Має бути 8.3 або новіше
  3. Поставити VS Code, у ньому — розширення PHP Intelephense
  4. У VS Code: File → Auto Save увімкнути
  5. Створити папку ~/code/php — латиницею, без пробілів

Термінал на Mac

  1. Зручніше працювати у вбудованому терміналі VS Code: Ctrl + ~ — він одразу відкритий у папці проєкту
  2. pwd — де я, ls — що тут лежить, cd — перейти
  3. open . відкриває поточну папку у Finder
  4. Перетягування папки з Finder у термінал вставляє її повний шлях
  5. Ctrl + C зупиняє будь-яку запущену програму

Git і GitHub

  1. Git на Mac уже є: git --version. Якщо система запропонує поставити Command Line Tools — погодитись
  2. git config --global user.name "Імʼя"
  3. git config --global user.email "пошта"
  4. Акаунт на GitHub — нік обрати нормальний, він залишиться надовго
Головна пастка macOS З версії Monterey Apple прибрала вбудований PHP, а на старіших системах він залишився дуже давній. Якщо php -v показує 7.x або 8.0 — це системний залишок, і частина прикладів курсу на ньому не запуститься. Потрібен свіжий PHP від Herd або brew install php; після встановлення обовʼязково закрити й відкрити термінал заново.
