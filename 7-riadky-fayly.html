Рядки, файли, помилки

Модуль, після якого програма перестає бути одноразовою. Досі все, що вона нарахувала, зникало разом із закриттям терміналу — тепер дані житимуть у файлах, а несподіванки не валитимуть програму. Це остання зупинка перед ООП.

Перед стартом

Модуль практичний: тут майже немає нових ідей, зате багато інструментів, які використовуються щодня. Головне — не заучувати назви функцій, а знати, що вони існують, і вміти знайти потрібну в документації.

Має бути засвоєно

  1. Власні функції з return і типами
  2. Масиви: індексовані, асоціативні, вкладені
  3. Розбиття проєкту на файли через require_once
  4. Читання помилки за номером рядка

Що зміниться

  1. Дані переживуть закриття програми
  2. Зʼявиться формат JSON — той самий, яким говорять усі веб-сервіси
  3. Програма перестане падати від дивного введення
  4. Кирилиця нарешті перестане ламати довжину рядків

Навіщо це для Laravel

  1. JSON — мова, якою фронтенд говорить із бекендом
  2. try/catch — основа обробки помилок у будь-якому фреймворку
  3. Робота з датами потрібна в кожному другому завданні
  4. Логи — перше, куди дивляться, коли на сервері щось зламалось
Одна звичка на весь модуль Для будь-якої дії з текстом спершу шукаємо функцію з префіксом mb_ — це версія, яка правильно рахує кирилицю. mb_strlen, mb_substr, mb_strtolower, mb_str_pad. Без цього префікса функція рахує байти, і українська літера важить дві. Половина дивних багів цього модуля — саме звідси.
