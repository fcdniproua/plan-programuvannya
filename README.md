# План навчання програмуванню

Матеріали для навчання підлітка веброзробці: від першого рядка PHP до фулстеку на Laravel + Vue.

Відкрити: **[index.html](index.html)**

|---|---|
| `index.html` | Стартова сторінка |
| `1-marshrut.html` | Карта на два роки: 11 етапів, 70 кроків з відмітками |
| `2-osnovy-php.html` | Поурочний план основ: 24 уроки, 97 завдань |
| `3-pershyi-misyats.html` | Сценарії занять, уроки 1–4 |

| `7-riadky-fayly.html` | Сценарії занять, уроки 13–15 |

## Як користуватись

Займаємось двічі на тиждень по 60–90 хвилин. Один урок плану = два заняття плюс домашка між ними.
Відмічені кроки зберігаються в браузері; кнопка «Зберегти у файл» вивантажує прогрес як JSON.

Усі інструкції зі встановлення розраховані на macOS і PHP 8.3+.

## Локально

Просто відкрити `index.html` у браузері — жодної збірки не потрібно.
